EasyLinux Installer

Bootable USB stick: pick a language, pick a profile, and it installs onto the first internal disk.

Download the newest ISO

All versions and checksums: Releases

Write the USB stick

  • balenaEtcher: select the ISO and the stick, then click Flash.
  • Rufus: when asked, choose DD mode.
  • Linux: sudo dd if=easylinux-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync

Requirements

  • UEFI PC with Secure Boot off
  • Network cable with internet access (profiles and packages are downloaded during installation)
  • ⚠️ The first internal disk is erased completely as soon as you click a profile.

Profiles

Profiles live in profiles/ and are downloaded fresh at every boot. Changes take effect without a new ISO.
