# EasyLinux Installer

Bootable UEFI USB stick that installs a Linux profile (NixOS or Debian) onto the first internal disk.

1. Pick a language
2. Pick a profile, and the installation starts

Profiles are downloaded from this repository at boot. GitHub Actions builds a new ISO monthly, and whenever the code changes.

See [docs/design-document.md](docs/design-document.md).
